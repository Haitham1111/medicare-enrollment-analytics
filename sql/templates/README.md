# SQL Templates (starter queries — not finished analysis)

These 10 files are **starter templates**: each one frames a real business
question against the CMS datasets and sketches the query shape
(CTEs, window functions, joins). Table and column names are placeholders —
each query is being rewritten against the actual loaded CMS tables as the
analysis progresses.

Finished, verified queries live in [`../queries/`](../queries/) and in
`drill-set-1.sql` (the SQL drill series run against the real data in SQL Server).

Do not cite these templates as results. They are scaffolding.
